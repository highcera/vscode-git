2. ChatGPT 복붙 vs 클로드코드 직접 실행

수업 목표
챗GPT와 클로드 코드의 차이점과 클로드 코드를 활용해 반복 업무를 자동화하는 방법에 대해 알아보도록 하겠습니다.

수업 내용
00:00
🧭 웹 기반 챗봇의 한계
웹사이트 기반 챗GPT는 로컬 파일을 직접 생성·수정 불가
파일 업로드를 통한 입력은 가능하지만 컴퓨터 내부 조작은 불가능
반복적인 복사·붙여넣기 작업이 번거로움

00:11
🔓 클로드 코드의 로컬 파일 접근성
클로드 코드는 특정 폴더의 파일을 읽고 생성·재활용 가능
로컬 파일 직접 조작으로 활용도 및 자동화 가능성 증가
결과물 저장과 재사용이 용이함

00:52
📋 수동 워크플로우 예시: 견적서 작성(챗GPT)
미팅 전사록·견적서 템플릿·단가표를 복사해 웹에 붙여넣기 필요
결과물 복사 후 메모장에 저장·이름 지정 등 여러 수작업 반복
고객마다 동일한 동작을 여러 번 반복해야 하는 비효율성

03:03
🗂️ 클로드 코드로 자동화된 폴더·파일 생성
VS코드 환경에서 폴더(입력·템플릿·결과)를 자동 생성 가능
전사록·템플릿·단가표를 폴더에 넣으면 이후 템플릿 재입력 불필요
프롬프트 실행만으로 견적서 초안 자동 생성

05:08
📁 자동 생성 결과와 재활용성
생성된 견적서가 결과 폴더에 자동 저장됨
파일 기반 저장으로 검색·정렬·재활용 용이
나중에 스킬화하면 프롬프트 입력조차 생략 가능

06:01
⚖️ 비교 평가: 속도·편의성·적합성
챗GPT 복붙 방식은 즉답성 우수하나 반복업무 효율성 낮음
클로드 코드는 파일 직접 처리로 자동화·보관·재사용에 유리
클로드 코드는 처리량이 많아 응답 속도는 상대적으로 느림
로컬 중심 작업으로 외부 데이터 노출 우려 감소 가능
소규모 사업자에게는 클로드 코드 기반 자동화가 더 적합

사내에서 클로드코드로 구현한 자동화 사례 네 가지를 살펴보고 각 업무에 적용하는 방법에 대해 알아보도록 하겠습니다.

수업 내용
00:00
🔎 사내 자동화 사례 개요
클로드코드로 개발팀 없이도 한 사람이 빠르게 구축한 사내 자동화 사례 소개
입력→처리→출력의 단순 구조 기반 자동화 설계
월간 작업 시간·비용 절감 및 초안 생성 후 사람 검수 방식으로 품질 유지

00:17
⚙️ 자동화 패턴 공통 구조
원본 입력, 지식베이스 구축, 처리 로직, 결과물 출력의 반복적 패턴
적용 시 고객 미팅·핵심 업무에 집중할 수 있는 시간 확보

01:08
🧾 견적서 자동화
고객 미팅 전사록과 단가표·템플릿을 입력해 MD/PDF 견적서 자동 생성
작성 시간 30~60분에서 검수 3분 수준으로 단축, 계산 실수 거의 제로화
신속한 발송으로 수주율 상승 효과 기대

03:16
📨 CS 답변 자동화
반복 문의(환불·수강기간·영수증·기술문제 등)를 템플릿과 지식베이스로 자동 응답 생성
이메일·카카오톡 연동으로 자동 수집·응답 확장 가능
응답 지연·톤 차이 감소로 클레임 감소 및 핵심 업무 우선순위 확보

04:46
📊 경쟁사·시장 조사 자동화
경쟁사 웹사이트·가격·메시지 등을 자동 수집·분석해 보고서 생성
검수 중심의 워크플로우로 리포트 품질 향상 및 시간 대폭 절감
미팅 횟수 증가로 매출 상승 기회 확대

05:48
🗓️ 콘텐츠 캘린더 자동화
원본 블로그 글을 기반으로 인스타·릴스·뉴스레터·엑스 등 채널별 포맷 자동 변환
캐러셀 이미지·영상 생성 및 편집도 AI로 보조하여 제작 시간 절감
채널 확장 시 콘텐츠 생산 병목 해소

07:00
🧩 자동화 적용 점검 및 우선순위 선정
내 업무와 사례 비교를 통해 입력 폴더·지식베이스·처리 로직 유사점 파악
절약 가능 시간·효과를 추정해 우선적으로 구축할 시스템 1개 선정
AI와의 대화를 통해 실제 구축할 시스템 설계 및 추천 받기

5. 전체 자동화 아키텍처 미리보기

수업 목표
전체 자동화를 위한 아키텍처와 클로드 코드 설치 및 활용 방법에 대해 알아보도록 하겠습니다.

수업 내용
00:00
🔎 전체 자동화 아키텍처 개요
클로드 코드 기반 전체 자동화의 전체 흐름 미리보기
입력 → 지식베이스 → 스킬 호출 → 결과물 생성 → 검수·발송의 기본 구조 소개

00:29
🧩 자동화 구성요소 설명
입력 폴더, 지식베이스, 클로드 코드(스킬 보유), 결과 폴더, 검수·발송의 6개 컴포넌트 설명
내 컴퓨터에서 모든 자동화가 진행되는 구조 강조

00:38
📁 입력 데이터와 지식베이스 구성
입력 폴더: 미팅 녹취, 이메일, 카톡, 원본 글 등 다양한 소스 저장
지식베이스: 단가표, 의사결정 기준, FAQ, 톤·미션 등 개인·업무 정보 저장
단순한 폴더 구조일수록 자동화 안정성 향상

00:57
⚙️ 스킬과 호출 방식
스킬: 견적서 작성, CS 응답, 웹 검색 등 작업 자동화 단위
슬래시 명령어로 스킬을 빠르게 호출
스킬 자체는 클로드 코드가 작성 가능하여 반복 프롬프트 제거

03:12
🌐 외부 데이터 연동(웹 검색)
내 컴퓨터에 없는 최신 정보(주가, 환율, 공시 등)를 웹에서 수집
수집한 최신 정보를 바탕으로 결과물 업데이트 및 누적 저장

03:46
👥 인간의 역할과 자동화 범위
사람의 역할: 입력 파일 저장, 스킬 호출, 최종 검수·발송
검수가 충분히 신뢰될 때까지는 사람의 검수 유지가 필요
이메일 자동 저장 등 입력 단계의 추가 자동화로 사람 개입 최소화 가능

05:16
🛠️ 실습 예시 및 우선순위 설정
자동화 지도 작성 권장: 1순위 자동화 대상 선정(예: 견적서 자동화)
견적서 자동화 구성: 입력 폴더(견적문의), 지식베이스(단가표·템플릿), 생성 파일(견적서)
학습 로드맵·우선순위 설정으로 27개 레슨 중 효율적 학습 가능

CHAPTER 2 클로드코드 설치와 첫 업무 지시

1. 클로드코드의 정체: 우리를 대신해 무엇을 해주는 도구인가

수업 목표
이번 시간에는 클로드 코드가 내 컴퓨터에서 반복 작업을 대신해 실행형 도구로 작동한다는 점에 대해 알아보도록 하겠습니다.

수업 내용
00:00
🔎 클로드 코드 개요
클로드 코드는 설치 후 내 컴퓨터 파일을 직접 읽고 생성·정리할 수 있는 실행형 AI 도구
설치만 하고 목적을 모르면 활용하지 못하는 경우가 많으므로 목적 파악 필요

01:18
⚙️ 챗봇과의 차이점
일반 챗봇은 텍스트 입력·출력 중심인 반면 클로드 코드는 컴퓨터 시스템·파일·브라우저 제어 가능
스킬로 반복 작업을 저장해 짧은 명령으로 자동 실행 가능

03:34
🧰 주요 기능 및 장점
내 컴퓨터의 여러 파일을 스스로 찾고 읽어 구조화·요약 가능
새 파일 생성 및 저장으로 결과물이 로컬에 남는 점
반복 작업 템플릿화로 초안 생성·업무 자동화 지원

05:41
🛡️ 한계와 책임
최종 판단·법적 책임은 사용자에게 있으며 중요한 계약·견적은 사람이 최종 검토 필요
예외처리 매뉴얼 없이는 적절 대응 불가하므로 사람의 컨트롤 필요

07:54
⚖️ 자동화 적용 원칙
모든 것을 완전 자동화하기보다 AI가 초안을 만들고 사람이 최종 검수하는 방식 권장
처음엔 70% 자동화를 목표로 단계적 적용 권장

08:46
📝 자동화 대상 선정 기준
정보 읽기·요약·정리처럼 형식화된 작업은 AI 자동화 적합
창의적 판단·고객관계·최종 가격 결정 등 책임이 큰 작업은 사람 결정을 유지
반복 패턴(데일리·주간 보고, 폴더 정리 등)은 자동화 우선 대상

12:17
💡 자동화 발굴용 프롬프트 팁
반복 업무 목록을 붙여 넣어 클로드 코드에 자동화 가능 영역·사람 판단 영역 분류 요청
우선순위 Top 3 추천 및 이유 기재 요청으로 실행 우선순위 결정
샘플 데이터로 먼저 테스트하고 민감정보는 초기에 제외 권장

13:09
🔚 수업 대상 및 마무리
코딩 몰라도 자연어로 지시해 사용할 수 있는 입문자 대상 수업
AI는 인간을 대체하는 것이 아니라 인간의 업무 수행을 돕는 도구라는 점 강조

2. 실습: 첫 대화 나누기, 내 배경화면 파일 목록 정리해줘

수업 내용
00:00
🧪 실습 시작 및 개요
첫 번째 실습 소개 및 목표 설명
클로드 코드와 바탕화면 파일 정리 실습 진행 안내

00:10
📁 VS 코드에서 폴더 열기
VS 코드 실행 후 Explorer의 Open Folder로 바탕화면 폴더 열기
왼쪽 패널에서 강의자료 폴더 확인 및 파일 미리보기

00:57
⚙️ 클로드 코드 실행 및 단축키
클로드 코드 실행방법: Windows Ctrl+~ 또는 Ctrl+J, Mac은 Cmd+~ 혹은 Cmd+J
토글 패널 메뉴에서 단축키 확인 및 슬래시 명령어로 도움말 접근

01:52
🖥️ 바탕화면 파일 준비 및 복사
실습 파일이 포함된 폴더를 파일 탐색기로 열어 바탕화면으로 복사
파일이 많거나 없을 경우 제공된 실습파일 사용 안내

03:48
🗂️ 정리 계획 요청의 중요성
바로 실행하지 않고 상황과 원하는 결과를 먼저 요청하는 계획 수립 강조
분류 기준(파일 형식·카테고리 등) 제시 후 컨펌 절차 권장

04:26
🔐 접근 권한 및 Auto 모드
바탕화면 접근 허용(일시허용, 항상허용, 거부) 선택 옵션 설명
Shift+Tab으로 Auto 모드 전환 가능, Auto 모드 활성화 시 권한 묻지 않음

05:36
🧭 파일 조회 및 명령 실행
클로드 코드가 PowerShell 명령(Get-ChildItem 등)으로 바탕화면 파일을 직접 읽음
Ctrl+O로 출력 확장 및 파일 목록 자동 조회 기능 설명

06:37
💬 계획 검토와 자동완성 활용
클로드 코드가 제안한 정리 계획 검토 및 컨펌 절차 설명
회색 제안 텍스트 탭으로 자동완성 적용, 원치 않으면 직접 입력 가능

08:11
🚚 정리 실행 및 결과 보고
파일 읽기 후 폴더 생성 및 파일 이동 실행 결과 보고(삭제·이동 항목 포함)
생성된 카테고리 예시: 영업견적, 재무회계, 고객응대, 회의록, 마케팅 등

09:49
📝 정리 결과 MD 저장 및 뷰어 설치
정리 결과를 MD(마크다운) 파일로 저장 가능 및 MD 문법(제목·강조 등) 설명
VS Code에서 보기 좋게 하기 위한 Office Viewer 확장 프로그램 설치 권장

🧭 파일 작업의 개요
파일 읽기·쓰기·정리의 정의와 중요성 설명
클로드 코드 사용 시 파일 작업이 거의 모든 업무의 출발점임

00:30
🔎 파일 작업의 업무적 의미
회의록·견적서·CS 답변 등 대부분의 자동화가 파일 기반으로 진행됨
원본 보존으로 검색·재사용·복구 용이성 확보

🖼️ 다양한 파일 형식 및 정리 방식

✍️ 데모: 회의록 요약 및 액션 아이템 추출
긴 회의록을 5줄 요약 및 결정사항·액션아이템 분리 요청

04:50

05:44
