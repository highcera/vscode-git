Chapter 03 보고서가 달라지는 서식 활용법

Lesson 01 반드시 숙지해야 할 셀 서식 기초
- 셀 서식 대화 상자 : ctrl+1
- 표시 형식은 겉으로 보이는 형식만 바꾼다
  : 숫자, 문자 혼용 시 수식 계산 오류 발생 -> 셀서식 적용
  : 적용 서식 확인 - 셀 서식 대화상자 >  표시 형식 > 사용자 지정 > 형식 입력란에서 서식 확인

- 실무상식 : 세미콜론으로 양수, 음수, 0, 텍스트 서식을 구분한다

Lesson 02 실무자를 위한 셀 표시 형식 대표 예제
[실무활용]
1. 0 지우거나 하이픈(-)으로 표시하기
  : #,##0;-#,##0::@ 0 대신 빈칸
  : #,##0;-#,##0:-:@ 0 대신 하이픈
  (Excel 옵션 > 고급 > 이 워크시트의 표시 옵션 > 0 값이 있는 셀에 0 표시 (sheet 단위)

2. 날짜를 년/월/일 (요일)로 표시하기
  : yyyy년 mm월 
  : yyyy-mm-dd (aaa)

3. 앞에 0이 포함된 숫자 만들기
  : 000000 (6자리 숫자)

4. 숫자 증감을 파알, 빨강으로 구분하여 표시하기
  : [파랑]▲#,##0;[빨강]▼#,##0;-;@
  : 양수;음수;0;그 외 텍스트는 그대로 표기
  : [노랑], [녹색] 혹은 [색1]. [색7] 총 56개 사용자 색상 지원
  : [빨강] 대신 [색9] 부드러운 느낌

5. 숫자를 한글로 표시하기
  : 표시형식 > 기타 > 형식 > 숫자(한글) 혹은 [DBNum4]
  : [DBNum4]일금* G/표준   * 뒷 문자 셀 끝가지 반복 열할

Lesson 03 깔끔한 보고서 작성을 위한 기본 규칙
1. 숫자는 무조건 오른쪽 정렬 /  문자는 왼쪽 정렬
2. 천 단위 구분 기호는 반드시 표시 (ctrl + shft + 1)
3. 단위가 다르면 반드시 명시 (표, 차트 오른쪽 위 단위 : 천달러, 입력된 당위가 여러가지 : 단위 열 추가)
4. 상/하위 항목 명확히 구분 - 들여쓰기
5. 표에서 세로선은 반드시 필요한 곳에만 사용 (가독성 향상)
   - 표 양 끝에 세로선 사용하지 않기
   - 주요 그룹별로 세로선 적용 (월별 - 분기별, 연도별 - 3~4 등분 세로선 적용, 가독성 향상, 중요 영역 실선, 나머지 영역 점선)

[실무활용]
1. 깔끔한 보고서 완성하기 (03-003.,xlsx)
  : 머리글 - 셀 서식 대화상자 > 테두리 > 스타일 - 굵은 실선 > 테두리 영역 - 위, 아래
  : 표시 형식  : 0.0%;[색9]-0.0%;-;@
  : 국가, 항목 구분 - 진한 회색 실선 테두리 추가
  : 9개 연도 데이터 3개씩 구분하는 세로선 추가
  : 사용자 입력 영역 [글꼴 색] 연한 파란색, 표시형싟 > 사용자 지정 #,##0
  : 리본메뉴 보기 > 표시 > 눈금선, 머리글 체크 햊데
