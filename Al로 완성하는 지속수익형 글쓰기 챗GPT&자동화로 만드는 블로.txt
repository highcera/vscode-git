# 포스팅 초안 만들기 프롬프트

아래 조건을 모두 반영해서 네이버 블로그용 포스팅을 작성해줘.

# 목표
- 네이버 검색 상위노출을 목표로, 
SEO에 최적화된 구조로 작성해줘. 

- 네이버 홈피드 노출을 목표로, 
가독성과 공감도를 높여 작성해줘.

# 제목
내가 선택한 제목을 그대로 사용

# 내용구성
아래에 붙여넣은 소제목 구조와 각 소제목의 핵심 내용을 기준으로
하나의 완성도 높은 포스팅으로 자연스럽게 연결해서 작성해줘.
(내가 선택한 소제목 구조& 내용 붙여넣기) 

#글 구성 및 분량 조건
- 도입부, 마무리: 공백 포함 약 250자
- 소제목별 본문: 각 공백 포함 350~400자
- 전체 분량: 공백 포함 총 2,500자 내외 (±100자 허용)

#줄바꿈 및 가독성
- 한 줄에 공백 포함 약 40글자 정도가 들어가도록 자연스럽게 줄바꿈
- 한 줄이 너무 길거나 짧지 않게, 리듬감 있게 문장을 나눠줘
- 줄글만 이어지지 않도록 중간에 소라벨, 강조 포인트를 적절히 사용

#표현 방식
- 친절하면서도 전문적인 톤의 존댓말로 작성
- 정보 전달 위주이되, 독자가 이해하기 쉽게 풀어서 설명
- 중요한 문장이나 핵심 포인트 앞에는
  📌, ☑️ 같은 이모티콘을 활용해 강조
- 전체 이모티콘 사용은 과하지 않게, 
가독성을 해치지 않는 선에서만 사용

#마무리 조건
- 작성이 끝난 후, 전체 글자수를 직접 확인하고
  요청한 분량 범위 안에 맞도록 문장을 조정해줘.

다음 방식으로 설계해줘.

- 하나의 공통 스타일 가이드(prompt)를 먼저 제시하고

- 이미지를 ‘동시에 여러 장’이 아니라
  ‘같은 프롬프트를 기준으로 1장씩 순차 생성’하도록 안내하는 구조로 작성해줘.

- 썸네일용 이미지 1장
- 본문용 이미지 4장
이다.

- 어떤 장면을 생성해야 하는지 명확히 구분해 주되
- 한 장에 하나의 장면만 나오도록 설계해줘.
- 콜라주, 패널, 분할 화면이 나오지 않도록 강하게 명시해줘.
