수업 목표
브랜드 리서치부터 아이덴티티 도출 및 페르소나 개발을 GPT로 실전 적용하는 방법에 대해 알아보도록 하겠습니다.

수업 내용
# GPT 어시스턴트 도입 이유
1. 브랜딩은 단순히 슬로건 제작이 아닌 전략적 사고와 일관된 콘텐츠 생산 필요
2. 전문성 한계 보완을 위해 GPT를 어시스턴트로 설정하여 부족한 부분 보완
3. 적은 인력으로 설계·기획 효율화 가능

# 브랜드용 GPT 유형
1. 전략 설계 담당 리서치·기획 어시스턴트
2. 시각 기반 비주얼 디자인 어시스턴트

# 리서치·전략 어시스턴트 역할
브랜드의 이유와 방향성을 구조화된 질문·분석으로 정리
자사·경쟁사·고객 분석과 포지셔닝 맵 생성
아이덴티티 기반 자료로 비주얼 설계의 기준점 제공

# 비주얼 디자인 어시스턴트 역할
1. 전략 결과물을 입력값으로 컬러·타이포·그래픽·포토·모션 가이드 설계
2. 페르소나 기반 시각화(외형·스타일) 제공
3. 트렌드보다 규칙·구조 중심의 디자인 시스템 구축에 초점

GPT 세팅 및 템플릿 제공
1. 이름·설명·스타터·지침을 포함한 세팅 포맷 제공
2. 노션 링크로 세팅 복사·붙여넣기 형태로 재사용 가능
3. 통합 브랜딩 전문가 역할로 기능 통합 지정

# 스타터 기능 및 자동화
1. 브랜드 탐색 질문 10개 생성 스타터 제공
2. 탐색 답변 기반으로 브랜드 리서치·아이덴티티·페르소나 도출 자동화
3. 불필요한 케이팝 특정 지침은 다른 브랜드용으로 제거 가능

리서치 핵심 축
1. 자사 분석
2. 경쟁사 분석
3. 환경 및 고객(트렌드·니즈·팬덤 관찰) 분석
4. 포지셔닝 맵으로 시각적 위치 도식화

브랜드 아이덴티티 요소
1. 미션: 존재 이유의 짧은 문구
2. 비전: 브랜드가 지향하는 미래 모습
3. 에센스: 핵심을 이루는 1~2단어
4. 코어 밸류·톤·태그라인 등 주요 요소 도출

# 페르소나 구체화 및 시각화
1. 이름·나이·신체·포지션·MBTI 등 상세 프로필 도출
2. 외형적 특징(눈·헤어·스타일) 및 성격·분위기 정의
3. 시각화용 이미지 리서치 및 반복 선택으로 최종화

# 브랜드 탐색 질문 예시
1. 브랜드명(없으면 GPT가 도출) 여부
2. 해결하고자 하는 문제·브랜드 부재 시 아쉬운 점
3. 전달해야 할 핵심 감정·세계관·레퍼런스 브랜드 3개
4. 브랜드 성격(조용함·적극성 등) 정의

# 브랜드 미학과 비주얼 디자인 어시스턴트 소개
1. 브랜드의 미학·컬러·팬 관계성 기반 비주얼 핵심 원칙 도출
2. 비주얼 디자인 어시스턴트(GPT) 역할 및 간단한 설명 정의
3. 시스템 프롬프트 준비와 다음 단계로의 전환 예고

# 입력·대화 스타터와 브랜드 페르소나 시각화
1. BX 리서치 결과물을 비주얼 어시스턴트에 입력해 추가 질문 진행
2. 브랜드 구체화를 위한 5가지 질문으로 디자인 시스템 도출
3. 브랜드 페르소나의 비주얼 레퍼런스·특징 도출을 통한 시각화 준비

# 디자인 시스템의 확장성과 적용 항목
1. 디자인 시스템은 SNS·앨범 커버·무대·숏폼 등 경험 단위로 확장 필요
2. 각 경험 단위에 맞춘 요소 설계 및 적용 방향 제시
3. 확장 시 사용자 경험 흐름과 성공 기준 제공 중요성

# 비주얼 어시스턴트 지침과 역할 정의
1. 입력된 BX 리서치·전략 해석 후 시각적 핵심 원칙·시스템 생성 역할
2. 디지털 콘텐츠·공간·제품으로의 단계별 확장 컨설팅 제공
3. GPT는 직접 이미지 생성하지 않음(설계·가이드 제공 중심)

프로세스·버전 관리 및 핵심 디자인 요소
1. 입력 문서(브랜드명·미션·코어밸류 등) 기반 추가 질문 수집
2. 디자인 시스템 변경 시 버전 표기 지침 적용
3. 컬러(브랜드 컬러·내추럴 컬러 총 13종), 타이포(헤드라인·본문·UI 구분), 로고 규칙·금기 제시 요청

# GFX·사진·모션 규칙과 페르소나 구체화
1. GFX(그래픽 이펙트) 용어와 설계 가이드 제공
2. 레퍼런스 없을 경우 브랜드 어센스 기반 시각적 메타포 제시
3. 사진·모션 규칙 및 페르소나 외형 묘사 후 이미지 생성 도구로 구체화 가능

# 경험 채널별 확장과 성공 기준 제공
1. 디지털 콘텐츠·캠페인·에디토리얼·모션·패키지·무대·전시 등 채널 확장
2. 각 채널별 원칙·사용자 경험 흐름·성공 기준 제공
3. 시스템 프롬프트를 실제 사용 환경에 그대로 적용 예정

## GPT 세팅 실습: UI 탐색 및 BX 리서치 GPT 생성

## GPT 설정 상세: 대화 스타터·모델·공유 설정
1. 대화 스타터 카드로 사용자 시작 문구 구성
2. 권장 모델 예시로 GPT-4o 설정 및 기본 코드 옵션 유지
3. 공유 설정에서 '나만 보기'로 저장하고 세팅 완료 후 GPT 보기로 확인

## 리서치 포맷 및 자사 분석 항목

# BX 리서치 GPT 활용 절차
1. 카드 UI에서 브랜드 탐색 질문 10개로 기초 정보 수집
2. 질문에 답변하여 브랜드 아이덴티티 시스템 도출 유도
3. GPT가 제공한 초안에 인간 해석과 추가 리서치 결합 필요

# 브랜드 네이밍 및 핵심 아이덴티티
1. 브랜드명 '쿼츠' 네이밍 배경: 수정의 정밀성·아름다움·기계적 메타포
2. 멤버 구성 메타포(네 명) 반영으로 브랜드 서사 강화
3. 브랜드가 해결할 문제: 기술 중심 AI를 인간적 감정으로 전환

# 브랜드 세계관 및 내러티브
1. 가상과 현실의 경계에서 현실로 진입하는 내러티브 지향
2. 일상 밀착형 서사로 인간적 온기 강조
3. 경쟁사(아일릿·르세라핌·에스파) 비교를 통해 포지셔닝 기준 마련

# 미학·톤·컬러 전략
1. 미학: 미니멀·키치·브루탈리즘 혼합 콘셉트 지향
2. 색상: 전기 신호·연결성 이미지를 반영한 블루 계열 추천
3. 관계성: 팬과 친구 같은 친밀한 관계성 표방, 차갑고 논리적 태도는 금기

## GPT 도출 결과 및 장단점
1. GPT가 제공한 브랜드 개요·강점·약점 초안 도출
2. 강점: AI의 인간적 재해석·케이팝 감성 차용 가능성
3. 약점: 기술 전문성으로 오해될 가능성·감성 과잉으로 인위적 접근 위험

# 포지셔닝·환경·타깃 인사이트
1. 포지셔닝 축: 기술↔감정, 현실성↔가상성으로 맵 구성

3. 쿼츠 포지셔닝: 감성적·현실적 위치로 아일릿과 유사한 영역 설정
