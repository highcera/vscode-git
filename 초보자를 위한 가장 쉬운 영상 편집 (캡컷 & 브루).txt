수업 내용
# 키프레임 개념
키프레임 정의: 시간축에서 속성 값이 바뀌는 기준 프레임
두 개 이상의 키프레임으로 시작값과 끝값을 달리해 값의 점진적 변화로 모션 생성

# 키프레임 설정 방법(확대 예시)
세부정보창의 속성 옆 마름모 클릭으로 키프레임 활성화
확대 값 변경으로 시작·끝 키프레임 설정해 줌인 모션 생성

## 키프레임 위치 조정
키프레임을 클립 시작·끝에 배치해 클립 전체에서 서서히 확대하도록 설정
키프레임 간격에 따라 모션의 속도 조절 가능

✂# 키프레임 복사·붙여넣기
키프레임 선택 후 복사(Ctrl+C)·붙여넣기(Ctrl+V)로 반복적 모션 구성
연속 키프레임으로 확대 후 원래 크기로 복귀하는 강조 줌 제작

## 키프레임 이징(사전설정)
키프레임 우클릭 후 사전설정에서 선형 또는 곡선 이징 선택
이징으로 값 변화의 속도와 느낌을 다양하게 조절

↔# 위치 애니메이션 설정(오른쪽 등장)
위치 X 값 조정으로 오른쪽에서 등장하는 애니메이션 생성
키프레임을 시작점·끝점에 배치해 등장 방향과 속도 제어

⬅# 위치 애니메이션 설정(왼쪽→오른쪽)
음수 X 값으로 좌측에서 등장하도록 설정해 좌→우 애니메이션 제작
키프레임 간격 축소로 등장 속도 증가 가능

# 변형 일괄 키프레임 설정
변형 항목의 마름모로 확대·위치·회전 등 한 번에 키프레임 설정 가능
한 위치에서 여러 속성의 값을 조정해 복합 모션 생성

## 불투명도로 페이드 인·아웃 만들기
클립 겹침과 불투명도 키프레임으로 자연스러운 페이드 인·아웃 구현
사전설정 이징으로 페이드 느낌 세부 조정 가능

편집 팁 및 요약
마커 사용으로 컷편집 속도 및 정확도 향상
메인 트랙 마그넷과 연결 설정은 필요에 따라 활성화·비활성화
속도 조절(표준·곡선·프리즈·역재생)로 강조 구간 제작
모자이크·배경제거 등 필요에 따라 다양한 방법 사용
핵심: 두 개 이상의 키프레임에 서로 다른 값을 주면 원하는 모션 완성됨, 반복 연습 권장

# 음량 노멀라이즈 및 단위 설명
음량 노멀라이즈는 목표 루프스(LUFS)에 맞춰 클립 평균 지각 음량 자동 보정
데시벨은 순간적 피크 크기, 루프스는 평균적 지각 음량을 나타냄

이큐, 치찰음 완화, 가벼운 컴프레서 등이 통합된 프리셋형 음성 보정 제공

노이즈 제거
환경 소음(바람, 차량 소리 등)을 자동으로 줄여주는 기능
세부값 미제공 단점이 있으나 일정한 노이즈 제거에는 효과적

# 노이즈 제거 vs 음성 보정 비교
노이즈 제거는 소음 감소에 유리하지만 울렁거림 발생 가능
음성 보정(강도 조절)은 현장감 유지하면서 깔끔한 음질 정리 가능

## 음성 분리
보컬 유지: 목소리 유지하고 배경음 제거
보컬 제거: 음악만 남기고 목소리 제거(내레이션 포함), 보컬 제거 성능은 상황에 따라 잔향 잔존 가능

# 유료 기능 적용 실습
내보낸 영상 파일을 타임라인에 올려 음성 보정·분리 등 유료 기능 적용 사례 시연
음성 보정 강도 테스트로 적정 강도(예: 50)가 청감상 더 나음

# 오디오 추출
영상에 포함된 오디오를 분리하여 별도 오디오 클립으로 만들기 가능
분리 후 음소거·재배치 등 편집 자유도 향상

## 무료 사용자용 오디오 분리 우회법
추출 불가 시 영상 클립을 복사해 다른 트랙에 올리고 불투명도 0%로 설정하여 오디오만 활용
속도 조정이 필요한 영상은 오디오를 미리 분리하거나 복사 방식으로 보존 권장

# 오디오 편집 기본 지침
헤드폰/이어폰 사용 권장
오디오 레벨 미터 활용으로 클리핑 방지 및 적정 볼륨 유지
내레이션 목표 레벨: -12 dB에서 -6 dB 권장, 플랫폼 목표 음량: -14 LUFS 권장

## 애니메이션과 편집 효과 차이

효과 트랙 위에 영상 클립을 놓으면 해당 영상에는 효과 미적용

적절한 사용: 흐름을 매끄럽게 하고 흥미 유발

편집 효과 적용 범위: 클립 전체 또는 구간 전체에 적용 가능
전환 효과 적용 범위: 두 클립 사이에만 적용
조정 가능 항목: 전환은 길이만 조절 가능, 세부 값은 불가

프리셋 사용 장점: 혼합 전환을 간단히 적용 가능

⬇# 전환 효과 적용 방법
다운로드/추가: 미사용 효과는 다운로드 후 플러스 버튼으로 적용
드래그 적용: 타임라인으로 끌어와 놓아도 적용 가능

## 전환 길이 조절 및 권장 시간

효과 속도 영향: 길게 하면 천천히, 짧게 하면 빠르게 나타남
권장 길이: 일반 전환(혼합)은 약 1초 권장

전체 적용 및 클립 길이 적응
전체 적용: 세부 정보창의 전체 적용 버튼으로 모든 전환 일괄 적용
클립 길이 적응: 캡컷은 클립 길이에 따라 적용 가능 길이 자동 조정
적용 결과 차이: 같은 전환이라도 위치에 따라 길이 달라짐

## 전환 삭제 및 마무리 원칙

# 색교정과 색보정의 개념 구분

색보정: 보정된 영상에 특정 색감을 입혀 분위기·감성 연출

## 색상 영역(온도·색조·채도)
온도: 왼쪽=차가운 푸른 톤, 오른쪽=따뜻한 노란/주황 톤
색조: 왼쪽=녹색, 오른쪽=보라색으로 전체 색상 톤 조절
채도: 낮추면 흐릿·흑백, 높이면 선명·생동감
화이트밸런스가 맞지 않을 때 온도로 중립색 복원
색상 개선 및 헤이즈 제거
헤이즈 제거: 안개·뿌연 먼지 제거로 선명도 향상
색상 개선: 자동 색감 향상으로 빠른 보정 가능
해당 기능은 유료 옵션일 수 있음

# 명도 영역(노출·대비·하이라이트·그림자 등)
노출: 전체 밝기 조절로 적정 밝기 확보
대비: 밝고 어두운 영역 차이로 입체감 부여, 과다 주의
하이라이트·그림자: 밝은·어두운 영역 디테일 복원
화이트·블랙·휘도: 영상의 최종 톤 정교화 및 밝기 독립 조절

## 편집 효과(선명하게·선명도·입자·비네트)
선명하게: 경계선·윤곽선 강조로 또렷함 부여
선명도: 중간톤 대비 향상으로 깨끗한 질감 연출
입자: 필름 느낌의 노이즈 추가로 빈티지 분위기
비네트: 가장자리 밝기 조절로 시선 유도·분위기 연출

# 색보정 3단계 워크플로우
1단계: 노출 및 대비 조절로 기본 밝기·입체감 확보
2단계: 온도·채도 조절로 원하는 색감 연출
3단계: 하이라이트·그림자·선명도로 디테일 마무리

# 필터 사용법
필터: 캡컷 기본 제공 색감 효과로 트랙이나 클립에 적용
필터 강도 조절 및 키프레임으로 구간별 변화 적용 가능
과하지 않게 강도 조절하여 자연스러운 분위기 연출

# LUT 활용법과 피부톤 보호
LUT: 전문적 색보정 도구로 큐브(.cube) 파일을 가져와 사용
큐브 파일 미리보기 후 타임라인에 드래그하여 적용
피부톤 보호 활성화로 인물 피부색 자연스럽게 유지

고급 색상 도구(HSL·곡선·컬러휠)
HSL: 색상·채도·밝기 항목별로 개별 조절
곡선: 어두운~밝은 영역을 미세하게 조절하여 톤 연출
컬러휠: 어두운·중간·밝은 영역에 각각 다른 색을 입히는 고급 보정
조정·필터·LUT 숙달 후 고급 도구 사용 권장

## 동영상 해상도 및 형식 설정
해상도는 소스와 동일하게 유지 추천(480p~4K 지원)
소스보다 높은 해상도 내보내기는 화질 향상 없음
동영상 활성화 체크로 결과물 영상 파일로 생성

## 비트전송률·CBR/VBR·코덱 설정
비트전송률은 화질·용량 균형 고려해 선택
권장값 예시: 1080p ≒ 8~12 Mbps, 2K ≒ 16~24 Mbps, 4K ≒ 25~45 Mbps
VBR은 장면에 따라 비트 조절해 효율성 우수, CBR은 고정비트 전송
코덱은 H.264(에이치이육사) 권장

# 파일 형식·프레임·오디오·캡션 설정
파일 형식은 MP4(Windows 권장) 또는 MOV 선택
프레임률은 원본 소스의 FPS 유지(예: 30fps)
오디오만 내보내기 가능(동영상 비활성화 후 오디오 활성화)
유료 사용자는 SRT 캡션 내보내기 및 GIF 고해상도 지원

# 내보내기 완료 및 확인
내보내기 진행 중 세부 정보 확인
완료 후 폴더 열기로 저장 경로 확인
완성 영상 플레이로 최종 확인 권장
플랫폼 업로드는 각 플랫폼에서 직접 진행 권장
