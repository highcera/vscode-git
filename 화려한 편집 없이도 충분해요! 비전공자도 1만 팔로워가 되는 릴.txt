# 유튜브의 특징
창의적이고 새로운 콘텐츠가 잘됨
단순 정보 전달보다 매력 있는 출연자 + 중독성 있는 말투 가 핵심
영상 스타일, 형식이 자유롭고 채널마다 다름

정보성 콘텐츠가 더 잘됨

형식을 따라하기 쉬워서 초보자에게 최적

[2. 초보자에게 인스타가 유리한 이유]
# 유튜브는 ‘재밌는 영상 만들어주세요’
→ 어렵고 막막함 #
→ 창의력 + 표현력이 필요함

# 인스타는 ‘내가 아는 정보만 전달하면 OK’
→ 일상 속에서 이미 알고 있는 정보로도 콘텐츠 가능!
→ 예시:
직장인 → 엑셀 함수 알려주기
엄마 → 아이 편식 해결 팁 공유하기

# 타겟의 고민을 해결해주는 정보
= 릴스 콘텐츠가 됨!
→ “내가 누군가에게 해줬던 말” = 콘텐츠

[3. 인스타에서 잘되는 콘텐츠 형식]
# 봤던 게 또 보이는 구조
비슷한 텍스트 / 멘트 / 영상 구도 / 음악
새로운 것보다 “익숙한 포맷”이 조회수↑

[1. 음성 녹음 방법]
# 왜 녹음이 필요할까요?
최근 릴스 트렌드는 음성 나레이션 포함 콘텐츠가 인기
AI 목소리, 변조된 음성 등도 활용 가능

# 녹음 방법 2가지
① 카카오톡 나와의 채팅 + 음성메시지 기능
녹음 → 전송 → PC에서 다운로드

② 스마트폰 기본 녹음 앱 (예: 아이폰 ‘음성 메모’)
녹음 후 카톡 등으로 전송

# 녹음 팁
핸드폰 마이크에 직접 대고 말지 말 것
입에서 조금 떨어진 곳 에 두고 녹음
배경 소음 없는 조용한 공간에서 녹음

[2. AI 자막 생성 – ‘브루’ 사용법]
# 브루 사용 이유
음성 인식률이 좋고, 자막 자동 생성 가능
무음 구간 줄이기 기능으로 편집 시간 대폭 단축

# 편집 순서
1. 브루 사이트 접속 → 새 프로젝트 열기
2. 녹음 파일 업로드 → 한국어 설정 확인
3. “무음 구간 줄이기” + “음성 미인식 구간도 함께 줄이기” 체크
4. 자막에서 말 더듬거나 어색한 부분 삭제
5. 완성된 음성 파일 → 오디오 파일로 추출

[3. 캡컷으로 영상 편집 시작하기]
# 기본 세팅
릴스는 세로 영상 (9:16) → 화면 비율 세팅 필수
상단 아이콘 → “세로” 클릭 → 편집 화면 넓게 보기 가능

# 음성 넣기
오디오 추가 → 오른쪽 클릭 → “오디오 분리”
노이즈 제거 기능으로 잡음 제거 가능

# 자막 자동 생성
1. 텍스트 → 자동 캡션
2. 자막 기준으로 말의 흐름에 맞춰 컷 편집
3. 말이 끊어지는 곳에서 영상도 컷 나누기

# 자막 편집 팁
캡션 편집창에서 전체 자막 텍스트 한 번에 수정 가능
자막 합치기: Delete
자막 나누기: Enter
두 줄 자막 만들기: 텍스트 편집창에서 Enter

⚠# 주의
자막은 1줄이 가독성 최고
두 줄 자막은 정말 필요할 때만!

[4. 목소리 없이 자막만 넣는 경우]
# 추천 자막 길이: 1.5~2초
1초 이하는 빠름
3초 이상은 지루함

# 편집 순서
1. 텍스트 → 기본 텍스트 → 복사 붙여넣기
2. 자막 타이밍 맞춰서 적절히 반복

하지만 음성이 없는 경우 어쩔 수 없는 선택!

# 컷 편집이란?
영상을 쪼개서 필요한 장면만 연결 하는 작업
불필요한 부분을 날리고, 템포 있게 릴스를 구성할 수 있음

# 영상 소스 종류
직접 촬영
화면 녹화
무료 영상 (픽셀스, 픽사베이)
AI 영상 (⚠# 추천 # – 피로감 있음)

[2. 얼굴/목소리 부담 있다면?]
# 아리너의 예시

대부분 화면 녹화 + 무관한 B-roll 영상 사용
외출할 땐 영상 몰아서 다수 촬영

# 자신의 성향을 존중하며 편집하자!
억지로 텐션 올리지 않아도 됨
차분한 스타일도 브랜딩 요소 가 될 수 있음

[3. 컷 편집 실습 – 자막 기준]
# 영상 가져오기
‘미디어’ → 영상 추가 → 타임라인에 드래그
나레이션 자막 흐름에 맞춰 영상 끊기

# 자르기 단축키
Q: 왼쪽 자르기
W: 오른쪽 자르기
Ctrl + B: 자르기 (추천 키 → C로 변경!)

# 단축키 커스터마이징 팁
상단 메뉴 → ‘쇼트컷’ 설정
Ctrl + B → C로 변경하면 손가락 위치가 편해져서 속도 UP

# 커서 놓고 흐름에 따라 자르기
자막 끊기는 부분마다 컷!
영상 부족하면 새로운 영상 넣고 이어서 자르기

# 원본 영상 소리 없애기
왼쪽 볼륨 버튼 클릭 → 트랙 음소거

[4. 컷 편집 실습 – 음악 박자 기준]
# 인스타 인기 음악 찾기
인스타 → 릴스 탐색
음악 클릭 → 오른쪽 아래 화살표 버튼 → 인기 음악 확인 가능
영상 저장 X, 단지 박자 추출용 녹화만 진행

# 음악 녹화 후 처리

캡컷에서 영상 넣고 → 오디오 추출
앞부분 정리 → 타임라인에 배치

# 비트 마커 찍기
오디오 선택 → AI 마커 추가 (비트1 or 비트2 선택)
마커 기준으로 영상 잘라서 붙이기
꿀팁: 정확한 마커보다 약간 앞에서 자르기 → 전문가처럼 보임

자막 선택 후 → [사전 설정으로 저장]
이후 텍스트 → [내 보관함]에서 사용 가능

4. 트랜지션 효과 & 화면 전환 연출
[수업목표]
릴스를 더 풍성하게 만들어주는 트랜지션, 키프레임, 마스크,
애니메이션 효과를 활용해 영상의 완성도를 높입니다.

[수업개요]
# 릴스는 계속 움직이는 화면 이 핵심!
# 컷 편집만으로는 아쉬울 때, 이 기능들로 재미를 더해줘요
# 남용은 금물! 필요한 포인트에만 활용할 것

[1. 트랜지션(전환 효과)]
# 트랜지션 위치
[전환] 탭 → 화면 전환 시 사용
컷 편집만 하면 “뚝뚝 끊기는” 느낌
→ 트랜지션으로 자연스럽게 연결 가능

# 사용할 때 주의사항
너무 많이 쓰면 산만함
릴스 분위기에 맞춰 사용
밝고 빠른 영상 → 역동적인 트랜지션
차분한 영상 → 부드러운 전환

# 추천 위치
콘텐츠 초반 or 후반
내용이 전환될 때
음악 박자 변화 시

# 속도 조절
트랜지션 길이 조절 가능 (짧게 = 빠른 전환)
뒤로 갈수록 더 짧게 하면 → 리듬감 UP, 지루함 DOWN

# 한 릴스에 몇 개?
1~2개 정도가 적당
너무 많으면 산만해보임

[2. 키프레임(움직이는 화면 만들기)]
# 키프레임이란?
영상의 크기/위치 등을 시간에 따라 변하게 만드는 기능
화면이 조용하거나 단조로울 때 시선 집중 유도

# 사용 예시
화면 확대
좌→우 이동
상→하 이동 등

# 사용법
영상 선택
[변형] → [키프레임 추가] (마름모 아이콘 클릭)
시간 이동 후 원하는 위치/크기 조절
→ 자동으로 부드럽게 변화됨

[3. 마스크(특정 부분만 보여주기)]
# 마스크란?
영상의 일부만 잘라서 보여주는 도구
B컷 영상, 자료화면 넣을 때 유용

# 활용 예시
종이컵 위에 와플 영상만 원형으로 보여주기
상단에 내 계정 정보만 노출하기
앱 화면의 일부분만 강조하기

# 사용법
영상 위에 다른 영상 or 이미지 올리기
[마스크] → [추가] → [원형/직사각형 등 선택]
위치 & 크기 조절

# 등장 애니메이션 추가 팁
마스크 영역을 뿅! 하고 보여주고 싶을 때
→ [애니메이션] → 등장 효과 설정

[4. 애니메이션 (자막/영상 움직임 효과)]
# 애니메이션이 필요한 이유
릴스는 계속 변화가 있어야 이탈 없이 시청
자막이든 영상이든 움직임 이 있어야 집중력 유지됨

# 애니메이션 vs 트랜지션
트랜지션 : 영상과 영상 사이 연결
애니메이션 : 한 영상 내 요소가 등장/이탈 할 때 사용

# 추천 효과
줌 인
밀기(슬라이드)

1. 릴스 영상 자료 촬영하는 법
[수업목표]

촬영이 어렵고 부담스럽다고 느끼는 분들도 쉽게 시작할 수 있도록 도와드릴게요.

# “뭘 찍어야 할지 모르겠어요”

집 안에서도, 외출 중에도, 특별한 장비 없이 부담 없이 찍을 수 있는 촬영법 을 알려드립니다.

[촬영 예시]
# 실내 촬영
먹는 영상 (음식, 과자 등)

타닥타닥 타이핑, 마우스 움직임

컴퓨터 화면 (설명 영상용)
카페 인테리어, 메뉴판, 콘센트 등

강남역 거리, 시장, 바닷가 풍경
걸어가는 길, 계단, 엘리베이터
종이컵 줌아웃, 간판, 카페 외관
행사장, 화장실 거울 등 공간 자체

# 특이 촬영
국자나 젓가락으로 음식 들어 올리기
면을 비비고 들어올리는 영상
언박싱, 노트북 열기, 손의 움직임
발가락 영상# (추천 X)

1. 가만히 들고 있기
움직이는 대상을 가만히 담는 방법
예: 버스가 다가오는 장면, 창밖 풍경

2. 좌우 이동
손목은 고정하고, 걷기만 해도 영상 완성
예: 카메라 들고 걸어가는 장면

3. 좌우 회전
음식 중심으로 동그랗게 도는 느낌으로
흔들림 줄이기 위해 손목은 고정

4. 확대(줌인)
멍하니 보게 만드는 핵심 효과
천천히, 부드럽게 줌인

5. 음식 퍼올리기
국자나 젓가락으로 살짝 들어올리기
보여주고 내려놓는 동작도 OK

6. 섞기 & 뒤적이기
면 비비기, 젓가락으로 흔들기
“움직임”만 있어도 영상이 된다!

7. 촬영 시작 팁
녹화 누르고 잠깐 기다렸다가 행동 시작
영상 자르기 쉽게 “앞뒤 여백” 만들기

2. 릴스 앞 3초 연출법

[1. 주제 선정이 가장 중요해요]
# 왜 주제가 먼저일까요?
본질이 없으면 후킹도 의미가 없다
계정의 방향성과 수익 구조를 먼저 정해야 한다

# 주제 선정 기준 3단계
1. 내가 관심 있는 주제 리스트업
2. 돈이 되는 주제인지 인스타와 크몽에서 조사
3. 나도 지금 당장 할 수 있는 주제부터 시작

# 조사 방법
인스타그램 탐색탭 → 관심 키워드 검색
계정 확인 → 프로필에 링크 유무 체크
(링크가 있으면 수익 활동 중일 가능성 높음)
링크 클릭 → 무슨 상품/서비스 판매 중인지 확인
크몽 검색 → 영상 편집 등 해당 서비스의 시세 및 초보자 진입 가능성 확인

# 주의사항
하고 싶은 것만 하지 말고, 수익 가능성 중심으로 선정
구조적으로 어렵거나 고수만 가능한 분야는 피하기

[2. 3초 후킹 연출법]
# 3초 안에 사람을 사로잡아야 합니다!

① 배경 영상
② 멘트(자막)
